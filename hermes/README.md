# thott.bot

thott.bot makes your AI an expert on World of Warcraft: Forever, from Blizzard's own game files for the build you're playing, current to the latest hotfix, with Blizzard's news and credited community data, drawn right in the chat.

## Use it

```bash
hermes plugins install thott-bot
hermes plugins enable thott-bot
hermes mcp add thott --url https://mcp.thott.bot/mcp --auth oauth
```

The first connection opens a sign-in page, where you sign in or create your free thott.bot account with Discord, Google or email.

To improve the service, thott.bot records what your AI asks it. We never see your conversation. We don't use it to train models. Using thott.bot requires an account. [Privacy policy](https://thott.bot/privacy)

thott.bot is not affiliated with Blizzard Entertainment, Wowhead, ZAM or the original Thottbot.
