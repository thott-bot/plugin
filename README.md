# thott.bot

Can your AI keep up with WoW Forever alone? Yeah, badly. It learned the game once and fills the gaps from secondhand sites that trail every patch. thott.bot gives it Blizzard's own game files instead, with every change minutes after it lands, even the silent ones. Building an addon? It has the game client's API, its combat restrictions and code examples too. Anything you'd look up is already in your chat. Close your tabs.

## Use it

This plugin adds thott.bot's server, `https://mcp.thott.bot/mcp`, to Cursor. The first connection opens thott.bot's sign-in, where a free account works.

Every other app: [thott.bot/setup](https://thott.bot/setup)
